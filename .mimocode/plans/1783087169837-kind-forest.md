# REST API Endpoints Feature - Implementation Plan

## Overview
Add JSON REST API endpoints to the FujiNet ESP32 HTTP server. This brings Mongoose-only features (printer status/clear) to ESP32 and adds a modern API for automation.

## Current State
- **ESP32 HTTP server**: ~20 HTML routes, no JSON API, uses `esp_http_server`
- **Mongoose (PC)**: Has `/printer/status`, `/printer/clear`, `/printer/events`, `/swap` - ESP32 lacks these
- **JSON library**: cJSON already included (`#include <cJSON.h>`) - supports both parsing and writing
- **Route registration**: Static array of `httpd_uri_t` structs in `httpService.cpp` lines 1700-1808

## API Endpoints to Add

### Phase 1: System Status (Easy)
| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/status` | GET | System info: version, IP, uptime, WiFi SSID, free heap |
| `/api/v1/config` | GET | Current configuration as JSON |

### Phase 2: Drive Management (Easy)
| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/drives` | GET | List all 8 drive slots with mount info |
| `/api/v1/drives/{slot}` | GET | Get specific drive slot details |
| `/api/v1/drives/{slot}/mount` | POST | Mount a disk image (JSON body: `{host_slot, path, mode}`) |
| `/api/v1/drives/{slot}/eject` | POST | Eject disk from slot |

### Phase 3: Host Management (Easy)
| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/hosts` | GET | List all 8 host slots |
| `/api/v1/hosts/{slot}` | GET | Get specific host slot |
| `/api/v1/hosts/{slot}` | POST | Update host slot (JSON body: `{hostname, type}`) |

### Phase 4: Printer (Medium) - Port from Mongoose
| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/printer/status` | GET | Printer status JSON |
| `/api/v1/printer/clear` | POST | Clear printer output |

### Phase 5: WiFi (Medium)
| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/wifi/scan` | POST | Scan WiFi networks |
| `/api/v1/wifi/status` | GET | Current WiFi connection info |

// Helper: Send JSON response
static void api_send_json(httpd_req_t *req, const char *json, int status = 200) {
    httpd_resp_set_status(req, status == 200 ? "200 OK" : "400 Bad Request");
    httpd_resp_set_type(req, "application/json");
    httpd_resp_send(req, json, strlen(json));
}

// GET /api/v1/status
esp_err_t fnHttpService::api_handler_status(httpd_req_t *req) {
    cJSON *root = cJSON_CreateObject();
    cJSON_AddStringToObject(root, "version", fnSystem.get_fujinet_version(true));
    cJSON_AddStringToObject(root, "ip", fnSystem.Net.get_ip4_address_str().c_str());
    cJSON_AddStringToObject(root, "hostname", fnSystem.Net.get_hostname().c_str());
    cJSON_AddNumberToObject(root, "uptime_s", fnSystem.get_uptime() / 1000000);
    cJSON_AddNumberToObject(root, "free_heap", fnSystem.get_free_heap_size());
    cJSON_AddStringToObject(root, "wifi_ssid", fnWiFi.get_current_ssid().c_str());
    cJSON_AddBoolToObject(root, "sd_present", fnSystem.check_sd());
    
    char *json = cJSON_PrintUnformatted(root);
    api_send_json(req, json);
    cJSON_free(json);
    cJSON_Delete(root);
    return ESP_OK;
}

// GET /api/v1/drives
esp_err_t fnHttpService::api_handler_drives(httpd_req_t *req) {
    cJSON *root = cJSON_CreateArray();
    for (int i = 0; i < MAX_MOUNT_SLOTS; i++) {
        cJSON *slot = cJSON_CreateObject();
        cJSON_AddNumberToObject(slot, "slot", i + 1);
        std::string path = Config.get_mount_path(i);
        cJSON_AddStringToObject(slot, "path", path.c_str());
        cJSON_AddBoolToObject(slot, "mounted", !path.empty());
        cJSON_AddStringToObject(slot, "mode", 
            Config.get_mount_mode(i) == fnConfig::MOUNTMODE_WRITE ? "w" : "r");
        cJSON_AddItemToArray(root, slot);
    }
    char *json = cJSON_PrintUnformatted(root);
    api_send_json(req, json);
    cJSON_free(json);
    cJSON_Delete(root);
    return ESP_OK;
}

// POST /api/v1/printer/clear
esp_err_t fnHttpService::api_handler_printer_clear(httpd_req_t *req) {
    PRINTER_CLASS *printer = (PRINTER_CLASS *)fnPrinters.get_ptr(0);
    if (printer && printer->getPrinterPtr()) {
        printer->getPrinterPtr()->closeOutput();
        printer->reset_printer();
    }
    cJSON *resp = cJSON_CreateObject();
    cJSON_AddStringToObject(resp, "status", "success");
    char *json = cJSON_PrintUnformatted(resp);
    api_send_json(req, json);
    cJSON_free(json);
    cJSON_Delete(resp);
    return ESP_OK;
}
